# Solventix Dental demo

A static, responsive dental website concept, preserving the original blue, white, and navy identity and clinic photography.

## Preview locally

From this directory:

    python -m http.server 4175

Open http://127.0.0.1:4175/.

## Experience

- Full-screen clinic hero and floating navigation
- Responsive photo gallery with accessible image dialogs
- Keyboard-accessible treatment explorer
- Two-step appointment preview with browser validation
- FAQ, reduced-motion support, mobile consultation action

This is a concept for review. The photographs and treatment categories are illustrative; no clinic identity, credentials, ratings, prices, or patient results are asserted. The appointment flow runs only in the browser and does not send, store, or book anything. Replace sample material and connect a real booking channel before using it as a clinic's operational website.

No build step, framework dependency, API keys, or backend are required.
